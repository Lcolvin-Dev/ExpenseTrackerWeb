# ExpenseTrackerWeb

A full-stack expense tracking web application built with ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server.

## Overview

ExpenseTrackerWeb allows users to manage and track expenses through a clean web interface. Users can create, view, update, and delete expenses while organizing spending information by category.

---

## Features

✔ Add new expenses

✔ View all expenses

✔ Delete expenses

✔ SQL database integration
